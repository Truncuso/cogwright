# Spike spec

## Design Question
State the how-should-it-look/behave/perform question in one sentence.

## Trigger Evidence
Name the fidelity.md two-part trigger this meets — why more talking or reading
will not settle it.

## Success Criteria
List each criterion as an observable, checkable statement — one per line.

## Branch
Name the branch — logic | ui | perf — and its findings template: LOGIC.md,
UI.md, or PERF.md.

## Expected Findings Shape
List the findings-doc sections the run must return, per the named branch template.
