# reference-ignore.txt — deliberate exceptions to the reference manifest.
#
# Applied at GENERATION time (scripts/goalforge-generate.sh): a matching token
# or resolved path is never written to
# plugins/goalforge/references/reference-manifest.json, so ci-lints and the
# doctor consume that manifest with no ignore-list of their own.
#
# One SCOPED entry per line, `<from-rel-path>::<token-pattern>` — the shape the
# baseline files use. The from-path is an fnmatch pattern against the scanning
# tree's root-relative source file (so one entry covers both the package tree,
# `harden/SKILL.md`, and the plugin tree, `skills/harden/SKILL.md`); the token
# part matches the raw token OR its resolved root-relative path, as an fnmatch
# glob or a literal prefix. The bare unscoped format is REJECTED — an entry that
# silences an address everywhere silences refs nobody adjudicated.
#
# Every entry here is an address OUTSIDE the tree being checked, not a dangling
# ref inside it. Entries are live: ci-lints.sh fails on an entry that suppresses
# nothing (the dead-entry leg of the same ratchet the baselines get).
