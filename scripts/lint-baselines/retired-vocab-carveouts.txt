# packages/goalforge/**/*.md + plugins/goalforge/**/*.md. Pattern: the
# case-sensitive literal `sdd-`.
#
# PURPOSE. The section is a ZERO-NEW ratchet, not a cleanup gate: every
# occurrence living on the tree when it was registered is carved out here with
# the work item that retires it, so its only signal is that a NEW retired
# `sdd-*` chain name cannot enter goalforge prose unreviewed.
#
# FORMAT, two shapes:
#   <repo-relative-path>::<literal line substring>   one known occurrence class
#   <repo-relative-path>::                           WHOLESALE — the whole file
# The wholesale (empty-substring) shape is used exactly twice, for the two
# copies of the alias map, whose entire purpose is the historic name mapping.
#
# REMOVAL-ONLY, same contract as the sibling baselines: an unbaselined
# occurrence is a violation, AND an entry that suppresses nothing is a
# violation. The file can only shrink on its own; every widening edit is a
# reviewable diff.
#
# NOT here, deliberately: `SDD_PLANS_DIR` carries an underscore, so the
# case-sensitive `sdd-` pattern never matches it — it is a spec §Non-Goal
# (deliberate retention), and an entry for it would be a dead entry.
# `_archived/**` is likewise absent: list_files() is `git ls-files`, and the
# only tree carrying `_archived/` is the gitignored plans/, so such an entry
# could never fire.
