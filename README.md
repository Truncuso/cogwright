# cogwright

A Claude Code plugin marketplace monorepo.

## Quickstart

```
/plugin marketplace add cunger/cogwright
/plugin install goalforge@cogwright
```

## Plugins

| Plugin | Description | Status |
|--------|-------------|--------|
| goalforge | Spec-driven development chain — goal-object work packages, harden/execute/verify lifecycle | scaffold — content migrating in |

## Roadmap

- **engram** — typed file+QMD memory vault
- **agent-dispatch** — cross-provider subagent dispatch
- **goalforge-viz** — plan visualization
- **command-center** — orchestration dashboard
