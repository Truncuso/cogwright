# Acknowledgements

The systems in this marketplace build on ideas, patterns, and teaching from
public creators and communities. This file is generated from typed source
records captured at the moment of adoption (see the provenance rule in each
system's docs); per-system credits live in each plugin's own documentation and
are aggregated here.

## How this file is maintained

Entries are not hand-curated after the fact: a detection hook flags adopted
external ideas missing a source record; intake happens in the adopting
artifact (`references[]` / `sources[]` / memory reference); an aggregation
script regenerates this file from records flagged `credit: true`. Corrections
and missing credits: please open an issue — miscrediting is a bug.
